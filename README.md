# Agenda web

Projecte web senzill creat per a les pràctiques de Git i GitHub.

## Pàgines
- `index.html`: pàgina principal de l'agenda.
- `contacte.html`: pàgina de contacte.
- `calendari.html`: pàgina del calendari (branca `feature/calendari` per simular el treball d'una col·laboració).

## Fitxers ignorats
La carpeta `tmp/` està inclosa a `.gitignore` i no es desa al repositori.

## Executar
Obre `index.html` amb un navegador o amb l'extensió Live Server de VS Code.

## Git
El repositori local inclou commits, una fusió de la branca `contacte` i un conflicte resolt entre `main` i `disseny`.
